# موقع مكتب صالح العمري للمحاماة

موقع Next.js بالعربية (RTL) مع لوحة تحكم كاملة، وقاعدة بيانات SQLite محلية — لا خدمات خارجية.

## المتطلبات

- Node.js **22.13 أو أحدث** (تُستخدم وحدة `node:sqlite` المدمجة)

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم عدّل بيانات أول مدير
npm run build
npm start                    # المنفذ 3000 افتراضيًا (npm start -- -p 8080 لتغييره)
```

للتطوير: `npm run dev`

عند أول تشغيل تُنشأ قاعدة البيانات في `storage/alomari.db`، ويُنقل إليها المحتوى الأولي من مجلد `data/`،
ويُنشأ حساب المدير من `ADMIN_EMAIL` و `ADMIN_PASSWORD`. بعدها يُدار كل شيء من لوحة التحكم.

## لوحة التحكم — `/admin`

| القسم | الوصف | الصلاحية |
|---|---|---|
| نظرة عامة | الزيارات والطلبات لآخر 30 يومًا، وأحدث الطلبات | مدير، محرر |
| طلبات الاستشارة | كل ما يُرسل من نموذج «اطلب استشارة»: الحالة، المحامي المسؤول، ملاحظات داخلية، مراسلة واتساب، تصدير CSV | مدير، محرر (الحذف للمدير) |
| الإحصاءات | الزيارات، الزوار، معدل التحويل، الصفحات، المصادر، الأجهزة، توزيع الطلبات (7/30/90 يومًا) | مدير، محرر |
| المحتوى | الخدمات، مجالات الممارسة، الفريق، الأدلة القانونية، الأسئلة الشائعة — إضافة وتعديل وحذف وترتيب | مدير، محرر |
| إعدادات الموقع | بيانات المكتب والتواصل والترخيص، المؤشرات، القيم، خطوات العمل | مدير |
| المستخدمون | إضافة الحسابات وتحديد الأدوار وتغيير كلمات المرور | مدير |

أي تعديل في المحتوى أو الإعدادات يظهر في الموقع فورًا (تُعاد توليد الصفحات تلقائيًا).

الإحصاءات لا تستخدم كوكيز ولا تحفظ عناوين IP؛ الزائر يُعرَّف ببصمة يومية مجهولة لا يمكن عكسها.

## بيانات تجريبية

لعرض اللوحة ببيانات واقعية (زيارات وطلبات لآخر 60 يومًا):

```bash
npm run demo:seed    # إضافة
npm run demo:clear   # حذف كل البيانات التجريبية فقط (قبل الإطلاق)
```

## النشر على خادم (VPS)

1. ثبّت Node.js 22.13+ وانسخ المشروع، ثم `npm ci && npm run build`.
2. شغّله بمدير عمليات مثل PM2: `pm2 start npm --name alomari -- start`.
3. ضع أمامه Nginx مع شهادة HTTPS (Let's Encrypt)، ومرّر الترويسة `X-Forwarded-Proto` — تُفعَّل بها كوكي الجلسة الآمنة.
4. **انسخ مجلد `storage/` احتياطيًا بانتظام** — فيه كل البيانات (المحتوى، الطلبات، المستخدمون).
5. حدّث «رابط الموقع» من إعدادات الموقع في اللوحة (يُستخدم في خريطة الموقع ومحركات البحث).
